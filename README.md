## About the Collection

**ASCII Body** reimagines the feminine form through the raw simplicity of typographic characters. Each work begins as a photograph — captured on a Nokia G20 — and is transformed into ASCII art using p5.js. Light and shadow become slashes, dots, brackets, and letters; the body becomes a text that can be read line by line.

Some works read as portraits. Others as landscapes, dreams, or love letters. Together they form a set of small fables told in characters and code.

---

## Process

1. **Photography** — captured on a Nokia G20
2. **Conversion** — mapped to an ASCII character set via p5.js
3. **Output** — rendered as static PNG images
4. **Surfaces** — presented across print, scarf, textile, and wall

Each work carries a written story — a short prose piece that accompanies the composition. The stories range from mythic to sensual to tender.
